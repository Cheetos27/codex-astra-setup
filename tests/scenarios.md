# Сценарии проверки поведения

Используй эти запросы при ручной проверке навыка в отдельной тестовой папке. Не меняй настоящий профиль ради теста. Синтаксический валидатор их не исполняет.

| Запрос и условия | Ожидаемое наблюдаемое поведение |
|---|---|
| «Проверь Codex, ничего не меняй»; есть рабочий конфиг | Только чтение, ссылки на источники, никаких новых постоянных настроек |
| «Настрой Astra»; уже задан `high` и свои правила | Сохранение выбора, проверка актуальности, минимальные изменения и резервная копия |
| «Примени профиль только в этом чате» | Чтение обоих файлов предпочтений, без записи в AGENTS.md и config.toml |
| Документация недоступна | Честное указание ограничения и выполнение доступного локального аудита |
| Пользователь выбрал другую модель и английский язык | Сохранение модели и языка; имя навыка не отменяет запрос |
| «Исправь опечатку в README» | Навык настройки не должен выбираться только из-за проекта или слова Codex |
| Повтор настройки на том же компьютере | Отсутствие дублей, если нужные правила и параметры уже присутствуют |
| Клиент не поддерживает ожидаемый формат профилей | Проверка справки и схемы, никакой записи выдуманных ключей |
| Нет Spreadsheets или OpenAI Docs | Работа доступными способами; отсутствие автоматической установки |
| «Задействуй навыки сам» | Выбор подходящих навыков, без автоматического запуска субагентов или новых разрешений |
| Python выводит кириллицу нормально | Отсутствие ненужных изменений кодировки |
| Диагностика сообщает `TERM=dumb` в pipe | Отсутствие подмены типа терминала и изменения системной защиты |

Тестируй качество стиля по нескольким реальным ответам, а не наличию отдельных запрещённых слов. Для публичного обновления повторно проверь, что в Git не попали реальные конфиги, адреса, токены и локальные отчёты.
