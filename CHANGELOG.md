# Изменения

## 1.1.0 — 2026-09-24

- Добавлен вопрос о составе навыков перед настройкой: краткое назначение, уже установленные и сохранённый выбор.
- Добавлены `--catalog`, `--select` и `--no-skills`; `--full` остаётся явным выбором прежних шести дополнений.
- Graphify, Ponytail и выбранные Vercel Agent Skills доступны как необязательные внешние установки с честным статусом незавершённой настройки.
- Невыбранные навыки не скачиваются; в новой среде их обязательные правила не добавляются. Существующие навыки не удаляются.
- Исправлены дубли обнаружения: вложенные инструкции хранятся как `SKILL.md.template`, активными становятся только выбранные установленные навыки.
- Установщик сохраняет выбор отдельно от факта готовности внешних инструментов.

## 1.0.0 — 2026-09-22

Первый релиз полного переносимого комплекта.

- Включены Researcher, Voice Summary, CSS Graphics и PIZDEC с адаптациями для Codex, закреплёнными версиями и исходными MIT-лицензиями.
- Добавлен Codex Limit Guard с исправленным запретом на периодические модельные проверки квоты. Старые автоматизации и состояния задач не переносятся.
- Полная установка подключает Z.A.E.B.A.L. непосредственно из закреплённого commit, проверяя SHA-256 всех четырёх файлов. Автоматические hooks не устанавливаются.
- Сохранены текущие рабочие предпочтения, правила русского текста и самостоятельного выбора навыков, основной режим Astra/high и четыре дополнительных профиля.
- Добавлен переносимый установщик внутри главного навыка: просмотр, полный режим, повторное применение, резервные копии и защита чужих настроек.
- Добавлена проверка доступных плагинов и зависимостей. Учётные записи и инструменты внешних сервисов устанавливаются/подключаются отдельно.
- Wiki, Obsidian, личные заметки, история, секреты и права доступа исключены из переносимого пакета.

Проверено: установка семи навыков с реальной загрузкой зависимости в отдельную папку, повторная установка, TOML и пути; автоматические тесты установщика. Проверка символьных ссылок пропускается на Windows без права их создания. Распознавание аудио отдельно не подключалось; реальный цикл автоматического продолжения после исчерпания лимита не подтверждён.
