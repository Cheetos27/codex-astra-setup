# Codex Astra Setup

**Версия 1.0.0 — переносимый комплект настроек Codex и рабочих навыков.** Одна просьба восстанавливает русскоязычный рабочий профиль, выбор подходящих навыков, настройки Astra и контроль лимитов. Личная wiki и Obsidian не входят.

Это независимый проект, не продукт OpenAI. Комплект сохраняет конкретные рабочие предпочтения; он не гарантирует лучший результат на каждой задаче и не переносит аккаунты или доступы.

## Быстрый запуск через Codex

Если навык уже установлен, напиши в новой задаче:

```text
Используй $codex-astra-setup. Восстанови весь мой комплект настроек
и навыков без wiki и Obsidian. Сохрани резервные копии и проверь готовность.
```

На новом компьютере дай Codex ссылку на этот репозиторий или скачанный релиз и попроси установить полный комплект. Для ручной установки нужны **Python 3.11+** и доступ к GitHub при первой загрузке Z.A.E.B.A.L.:

```text
git clone https://github.com/Cheetos27/codex-astra-setup.git
cd codex-astra-setup
python install.py --full
python install.py --full --apply
```

Первый запуск показывает план без записи и сети. Второй устанавливает семь навыков, дополняет личные инструкции и применяет перечисленные ниже настройки. На Windows можно использовать `py -3.11` или доступный Python более новой версии.

## Состав

| Навык | Назначение |
|---|---|
| codex-astra-setup | Проверка среды и восстановление комплекта |
| researcher | Исследования и проверка первичных источников |
| voice-summary | Выжимки из расшифровок; для аудио требуется доступное распознавание |
| css-graphics | HTML/CSS/SVG-графика и экспорт PNG/JPEG |
| pizdec | Аудит безопасности разрешённой цели без её изменения |
| codex-limit-guard | Сохранение работы при низком остатке квоты |
| zaebal | Разбор ошибок по протоколу Z.A.E.B.A.L., без установки hook |

Четыре навыка howdeploy включены с закреплёнными версиями, адаптациями для Codex и лицензиями. Z.A.E.B.A.L. скачивается непосредственно у автора из закреплённого commit; каждый файл проверяется по SHA-256. [Происхождение материалов](THIRD_PARTY_NOTICES.md).

Автоматический выбор разрешён, но навыки применяются по условиям задачи, а не все одновременно. Клиент должен обнаружить установленные навыки; для этого может понадобиться новая задача или перезапуск. Установка инструкций не предоставляет отсутствующие инструменты.

## Какие настройки восстанавливаются

- Русский язык, понятные формулировки, редакционные правила против шаблонного текста.
- Самостоятельное выполнение согласованной работы, сохранение контекста, проверки и резервные копии.
- Выбор подходящих навыков; субагенты по запросу на делегирование или параллельную работу.
- Основной режим: `gpt-6-astra`, reasoning `high`, verbosity `low`, personality `pragmatic`, web search `live`, service tier `default`.
- Профили `astra-quick`/`low`, `astra-balanced`/`medium`, `astra-deep`/`xhigh`, `astra-max`/`max`.
- UTF-8 для дочернего Python на Windows.
- Контроль лимитов во всех задачах: проверка внутри работы, сохранение при 5%, остановка при 1%. Возобновление допустимо только с подтверждённым первым запуском после сброса блокирующих лимитов. Постоянный опрос, фоновые наблюдатели и reset credits не используются; полный естественный цикл автоматического продолжения пока не подтверждён.

Профиль рассчитан на владельца, который выбрал эти настройки. Перед восстановлением Codex проверяет актуальную документацию и поддержку параметров. Выбранная модель открытой задачи не переключается от изменения файла. Изменения применяются к последующим запускам с учётом проектных и пользовательских переопределений.

Плагины GitHub, Figma, документы, таблицы, визуализации и другие возможности описаны в [списке проверок](skills/codex-astra-setup/references/plugins-and-tools.md). Их кэш и авторизации не копируются. Отсутствующее подключение отражается в отчёте, а не считается рабочим.

## Другие режимы

Только главный навык, без изменения настроек:

```text
python install.py --apply
```

Аудит: `Используй $codex-astra-setup. Проверь настройки, ничего не меняй.`

Только текущий разговор: `Примени рабочие предпочтения из $codex-astra-setup только в этом чате.`

Этот комплект предназначен для Codex со средой установки. Обычный разговор на chatgpt.com не получает инструменты и глобальные настройки от текста навыка.

## Обновление и пути

```text
python install.py --full --update
python install.py --full --update --apply
```

По умолчанию установщик использует `$CODEX_HOME/skills`, иначе `~/.codex/skills` — каталог проверенной desktop-среды. Если клиент обнаруживает навыки в другом месте, укажи `--skills-dir`; для настроек отдельно укажи `--codex-home`. Актуальная документация также описывает `~/.agents/skills`.

Установщик не удаляет посторонние навыки и сохраняет посторонние TOML-ключи. При изменении существующих файлов создаёт резервные копии в `skill-backups` и `setup-backups`, выводя пути. Повторный запуск с тем же комплектом не дублирует инструкции. Полное обновление заменяет выбранные версии навыков: сначала изучи план, если менял их сам. Существующие личные инструкции сохраняются; противоречия профиля с явными предпочтениями нужно разрешить до применения.

Откат: сохрани новые пользовательские изменения и восстанови конкретные файлы или папки из выведенных резервных копий. Файл `*.previously-absent` означает, что соответствующий файл до установки отсутствовал. Весь комплект не является одной транзакцией; после частичного сбоя проверь завершённые шаги.

## Проверки

```text
python -B -m unittest discover -s tests -v
```

Проверяются установка и обновление, отсутствие записи при просмотре, повторный запуск, конфликты, резервные копии, ошибки скачивания, синтаксис TOML, сохранение посторонних настроек и запуск из уже установленного навыка. Готовность внешних сервисов проверяется отдельно. Для структуры навыков используется официальный `quick_validate.py` при доступном PyYAML.
