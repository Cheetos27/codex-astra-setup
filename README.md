# Codex Astra Setup

Навык для настройки **Codex и GPT-6 Astra** с русскоязычными рабочими предпочтениями. Проверяет актуальную документацию, учитывает установленный клиент и помогает переносить настройки между задачами и компьютерами.

Пакет появился из практической настройки Codex. Он сохраняет рабочий подход и примеры, а изменчивые параметры проверяет заново. Независимый проект; не связан с OpenAI и не гарантирует прирост качества на любой задаче.

## Что входит

- Проверка официальной документации Astra и поддерживаемых параметров Codex.
- Самостоятельная работа в согласованных границах, продолжение после сжатия контекста, восстановление после ошибок инструментов.
- Выбор подходящих доступных навыков без необходимости называть каждый из них.
- Русский текст с конкретными формулировками и без скоплений шаблонных оборотов.
- Соразмерные проверки, резервные копии, аккуратное дополнение AGENTS.md.
- Проверка среды выполнения и кодировки Python на Windows при соответствующей проблеме.

Личные токены, история чатов, реальные конфиги и пути автора в пакет не входят. Навык не устанавливает другие плагины, не повышает права и не включает автоматически платные режимы.

## Установка

Скачай репозиторий или клонируй:

```text
git clone https://github.com/Cheetos27/codex-astra-setup.git
cd codex-astra-setup
```

С Python 3.10+ проверь план установки:

```text
python install.py
```

Установи навык:

```text
python install.py --apply
```

Если Python вызывается иначе, используй соответствующий исполняемый файл, например `py -3` в Windows. Установщик использует только стандартную библиотеку и работает без сети. По умолчанию он копирует навык в `$CODEX_HOME/skills`, а если переменная не задана — в `~/.codex/skills`. Путь можно указать через `--skills-dir`.

Установка копирует только навык. Она **не применяет настройки Codex и не редактирует AGENTS.md**. Настройка происходит по твоему следующему поручению. Если навык не появился, начни новую задачу или перезапусти клиент.

Также можно вручную скопировать папку `skills/codex-astra-setup` в каталог навыков, поддерживаемый твоей версией Codex, или поручить доступному Skill Installer установить её из этого репозитория.

## Использование

Для проверки без изменений:

```text
Используй $codex-astra-setup. Проверь Codex и доступность GPT-6 Astra.
Ничего не меняй; покажи только обоснованные рекомендации.
```

Для настройки:

```text
Используй $codex-astra-setup. Настрой Codex для работы с Astra,
дополни личные инструкции подходящими правилами из навыка.
Сохрани мои существующие предпочтения и подготовь откат.
```

Для текущего диалога:

```text
Примени рабочий профиль и правила русского текста из $codex-astra-setup
только в этом чате, без изменения файлов.
```

Навык доступен для автоматического выбора, когда задача касается такой настройки. Он не должен запускаться на каждый обычный запрос. Постоянные предпочтения сохраняются в AGENTS.md только в рамках соответствующего поручения. Установка навыка сама по себе не меняет модель открытой задачи.

## Дополнительно: Z.A.E.B.A.L.

С навыком можно использовать [Z.A.E.B.A.L. от howdeploy](https://github.com/howdeploy/Z.A.E.B.A.L) для разбора ошибок агента. Мы добавили [инструкцию подключения](skills/codex-astra-setup/references/zaebal-integration.md); сам сторонний навык устанавливается отдельно и не входит в пакет.

Для установки через Codex:

```text
Используй Skill Installer. Установи навык из howdeploy/Z.A.E.B.A.L,
путь skills/zaebal, ref ea5e18fb2c5b8ec700fb4ad36bad5f91bd8c269d.
Установи только навык, без автоматического hook.
```

После установки можно написать: `Используй $zaebal и разбери повторяющуюся ошибку в этой задаче`. Навык также имеет собственные условия автоматического выбора. Его режим аудита может приостанавливать работу и запрашивать подтверждение продолжения. Автоматический hook со счётчиком инцидентов и внешним CLI-аудитором требует отдельной настройки; наш установщик его не включает.

## Что стоит адаптировать под себя

Русский язык, краткая подача, редакционные рекомендации и правило явного запроса на субагентов входят в предлагаемый профиль. Более конкретные предпочтения пользователя сохраняются. Уровень `high` из исходной настройки не навязывается всем; подходящий режим выбирается по задаче и возможностям клиента.

Подробный материал о стиле находится в [russian-writing.md](skills/codex-astra-setup/references/russian-writing.md). Это редакционные пожелания, не детектор ИИ-текста.

## Обновление и удаление

После загрузки новой версии сначала посмотри план, затем явно разреши обновление:

```text
python install.py --update
python install.py --update --apply
```

Установщик сохраняет прежнюю папку целиком и выводит её путь. При совпадении файлов повторная установка ничего не меняет. Существующая отличающаяся версия без `--update` не перезаписывается.

Для удаления убери только установленную папку `codex-astra-setup`. Для отката обновления перемести текущую папку в безопасное место и верни резервную копию по прежнему пути. Это не откатывает отдельно применённые настройки Codex: у них должны быть свои резервные копии, созданные во время настройки.

## Проверка разработки

```text
python -m unittest discover -s tests -v
```

Тесты проверяют установку в отдельном временном каталоге, отсутствие записи при предварительном просмотре, повторный запуск, защиту существующей версии и резервное копирование. В Codex дополнительно используй штатный `quick_validate.py` из доступного Skill Creator для папки `skills/codex-astra-setup`.

Сценарии поведения для ручной проверки описаны в [tests/scenarios.md](tests/scenarios.md). Синтаксическая проверка и тесты установщика не доказывают, что модель всегда правильно применит навык.
