# Выбор навыков при настройке

Перед установкой дополнений прочитай `assets/skill-catalog.json`, проверь уже установленные навыки и сохранённый выбор `$CODEX_HOME/astra-setup-selection.json`, если он есть. Этот файл отражает выбор, а не доказательство успешной установки внешних инструментов.

## Один понятный вопрос

При общем запросе «настрой Codex/Astra», включая «восстанови комплект», сначала предложи список названий с кратким назначением из каталога и спроси: «Какие навыки подключить? Можно перечислить названия или номера, выбрать прежний набор либо настроить Codex без дополнительных навыков». Отметь уже установленные. Не предвыбирай Graphify, Ponytail или всю коллекцию Vercel.

Используй доступный инструмент вопросов или задай вопрос обычным сообщением. Пока ответа нет, можно проверять среду и готовить настройку; не устанавливай дополнения и не добавляй обязательные правила их запуска. Отсутствие ответа не означает согласие. Явно указанные пользователем список, «без дополнительных навыков», «прежний набор» при доступном сохранённом выборе или «все шесть из базового комплекта» уже являются выбором; второй раз не спрашивай. «Все» при показанном каталоге включает перечисленные внешние дополнения, а не только шесть базовых.

Пример компактного списка:

1. Researcher — исследования и источники.
2. Voice Summary — выжимки из аудио/текста.
3. CSS Graphics — баннеры и карточки.
4. PIZDEC — аудит безопасности.
5. Limit Guard — сохранение при исчерпании квоты.
6. Z.A.E.B.A.L. — разбор ошибок агента.
7. Graphify — связи в проекте и документах.
8. Ponytail — простые решения без лишнего кода.
9. Vercel Agent Skills — выбранные навыки для веб-разработки.

При выборе Vercel предложи подходящие конкретные навыки по известному стеку; уточняй состав, если определить его нельзя. Не устанавливай целую коллекцию из-за одного подходящего навыка. OmniRoute — отдельный шлюз моделей; этот выбор его не устанавливает.

## Применение выбора

Сначала план, затем те же аргументы с `--apply`, когда выбор уже дан:

```text
python scripts/install_bundle.py --select researcher,css-graphics --update
python scripts/install_bundle.py --select researcher,css-graphics --update --apply
```

`--no-skills` применяет настройки без установки дополнительных навыков; `--full` явно выбирает прежние шесть (не внешние дополнения); `--catalog` показывает список без записи и сети. Обычный запуск без этих флагов устанавливает только главный навык. Повтор установки не удаляет и не отключает ранее установленные, но не выбранные навыки: снятие выбора означает пропустить установку в этом запуске. Удаление или отключение требует отдельного поручения. Существующие явные глобальные предпочтения также сохраняются.

В чистой среде инструкции запуска Limit Guard и других дополнений добавляются только для выбранных базовых навыков. Вложенные инструкции хранятся как `SKILL.md.template` и становятся `SKILL.md` лишь при установке выбранного навыка; они не должны обнаруживаться как установленные копии внутри главного навыка.

## Внешние дополнения

При выборе `graphify`, `ponytail` или `vercel-agent-skills` установщик сохраняет выбор, но возвращает `needs_assisted_setup` с перечнем необходимых действий. Это НЕ успешная установка этих дополнений. Продолжи установку в том же поручении средствами агента; не останавливайся на сохранённом выборе.

- **Graphify:** открой актуальные инструкции указанного репозитория, проверь доступный Python и уже установленный пакет `graphifyy`. При отсутствии установи поддерживаемым способом в отдельное окружение, затем установи интеграцию именно для Codex в обнаруживаемый каталог. Проверь версию, загрузку навыка и небольшой пример по доступным средствам. Не включай автоматически экспериментальные флаги, параллельных агентов, передачу файлов внешнему сервису или платный API. Индексация всего проекта — отдельная работа, если она не поручена.
- **Ponytail:** прочитай выбранную версию инструкций и подключи навык или штатный плагин с учётом целевой среды. Различай установку инструкций и hooks. Выбор навыка не разрешает автоматически регистрировать исполняемые hooks; этот состав сначала покажи пользователю, если они нужны.
- **Vercel Agent Skills:** используй Skill Installer для конкретно выбранных папок официального репозитория. Проверь зависимости и отсутствие противоречий с рабочим профилем. Выбор навыка деплоя не является поручением опубликовать проект.

Сохраняй закреплённые версии и проверенный результат. После фактической проверки каждого дополнения убери его ID из `pending_assisted` сохранённого выбора с резервной копией. При блокере оставь ID там и точно сообщи недостающий инструмент или решение. Не копируй ключи и авторизации в комплект.
