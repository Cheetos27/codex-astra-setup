# Восстановление полного комплекта

Версия комплекта: 1.1.0. Проверено 2026-09-24. Python 3.11+, стандартная библиотека; первая установка Z.A.E.B.A.L. требует доступа к raw.githubusercontent.com.

## Состав

Перед установкой спроси о выборе по [skill-selection.md](skill-selection.md). В базовом каталоге доступны `researcher`, `voice-summary`, `css-graphics`, `pizdec`, `codex-limit-guard` и `zaebal`. Первые пять хранятся как шаблоны в `assets/skills` и устанавливаются только по выбору. Graphify, Ponytail и выбранные навыки Vercel доступны как внешние дополнения с отдельной установкой. Z.A.E.B.A.L. скачивается из закреплённого commit с проверкой SHA-256 каждого файла: в его репозитории не обнаружена лицензия на распространение, поэтому исходники не перепубликуются в нашем комплекте. Состав и хеши — в `assets/bundle.json`.

Режим восстановления переносит текущий профиль автора: Astra/high, краткость low, pragmatic, live web search, обычный service tier; четыре именованных профиля и UTF-8 для Python на Windows. Он не предназначен для универсальной замены предпочтений другого пользователя. Источник значений — `assets/settings.json`; поддержка на целевом клиенте проверяется до записи.

## Порядок

1. Прочитай текущие инструкции и безопасную выборку конфигурации, проверь поддержку модели и полей. Если пользователь выбрал другую модель или запретил постоянные изменения, не запускай полный режим. Для выборочного переноса используй инструкции и ресурсы, сохраняя явные исключения.
2. Определи каталог навыков, который обнаруживает установленный клиент, и CODEX_HOME. Этот desktop-профиль проверен с `$CODEX_HOME/skills`; актуальная общая документация также описывает `$HOME/.agents/skills`. Не создавай две копии автоматически. Для другого расположения передай `--skills-dir` и `--codex-home` явно.
3. После ответа выполни предварительный просмотр: `python <папка-навыка>/scripts/install_bundle.py --select researcher,css-graphics --update`, подставив выбранные ID. Для отсутствия дополнений — `--no-skills`; `--full` допустим только при явном выборе всех шести базовых навыков. Он не меняет установку и не обращается в сеть. Параметр `--update` разрешает замену только главного и выбранных навыков с резервными копиями. Проверь пользовательские изменения и конкурирующие правила перед применением.
4. После подтверждённого выбора выполни ту же команду с `--apply`. Если возвращён `needs_assisted_setup`, заверши выбранные внешние установки по skill-selection.md и проверь их фактическую готовность. Повторное разрешение на уже порученный перенос не нужно. В остальных случаях ограничься запрошенным аудитом или настройкой текущего чата. Установщик скачивает только закреплённые файлы zaebal, проверяет их до изменения установки; hook не запускает. Новые блоки предпочтений не отменяют явные локальные исключения: при конфликте сначала согласуй содержимое с текущим запросом.
5. Установщик делает резервные копии изменяемых навыков в `skill-backups`, конфигурации — в `setup-backups`, проверяет совпадение записанных файлов. Он сохраняет посторонние файлы и TOML-ключи. Отдельные записи атомарны; весь комплект не является одной транзакцией. При сбое посмотри уже выполненные изменения и резервные копии, не объявляй всё установленным.
6. Проверь обнаружение выбранных навыков без дублей и отсутствие их отключения в `skills.config`, синтаксис TOML, актуальный каталог моделей. Известный явный запрет владельца не снимай молча. Проверь доступные средства по таблице ниже и `plugins-and-tools.md`. Перезапуск или новая задача могут потребоваться; файл на диске ещё не доказывает загрузку клиентом.

## Проверка готовности

| Возможность | Что проверить |
|---|---|
| Researcher | Доступен веб-поиск и чтение первичных источников; Hermes/Tavily не обязательны |
| Voice Summary | Готовая расшифровка либо подключённое распознавание. Отсутствие Speech-to-Text сообщить; ключи не переносить |
| CSS Graphics | Node, Playwright и браузер; на проверенном Windows используется Edge. В другой среде указать доступный браузер и проверить реальный экспорт |
| PIZDEC | Аудит только разрешённой цели; доступность анализаторов проверяется перед использованием |
| Limit Guard | Свежий get_usage_limits; проверка внутри работы. Никаких периодических наблюдателей, фоновых агентов и переноса старых checkpoint/автоматизаций |
| Z.A.E.B.A.L. | Навык отдельно от hook. Действуют точные условия протокола и разрешения среды |

Obsidian, local-wiki, заметки, история, аккаунты, секреты, настройки разрешений, старые расписания и состояние задач исключены. Уже имеющиеся файлы базы и её правила не удаляются. На chatgpt.com без среды установки такой пакет нельзя считать подключённым: можно применить текстовый профиль текущего разговора, но не обещать инструменты Codex.

## Откат

Пути резервных копий выводятся в результате. Перед откатом сохрани изменения, сделанные после установки. Верни конкретный файл/папку из соответствующей копии; отметка `*.previously-absent` означает, что файл был создан установщиком. Не восстанавливай весь домашний каталог и не удаляй чужие навыки.
