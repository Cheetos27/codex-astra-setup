# Плагины и инструменты

Снимок доступных возможностей исходной среды, 2026-09-22. Наличие инструкции не предоставляет доступ к сервису. При переносе сначала получи текущий каталог; имена и упаковка плагинов меняются.

| Задача | Доступные в исходной среде средства |
|---|---|
| Репозитории и ревью | GitHub, Git, браузер |
| Дизайн и прототипы | Figma, Product Design, Creative Production |
| Создание и размещение сайтов | Sites |
| Документы, PDF, таблицы, слайды | Documents, PDF, Spreadsheets, Presentations |
| Повторные шаблоны | Template Creator |
| Иллюстрации и редактирование растровых изображений | Imagegen |
| Наглядные объяснения | Visualize |
| Браузер и приложения | Доступные browser/computer-use инструменты с их фактическими границами |
| Управление задачами и лимитами | Codex app tools |
| Настройка среды | OpenAI Docs, Skill Creator, Skill Installer, Plugin Management |

Автоматически выбирай установленные средства по задаче и читай соответствующий SKILL.md. Не копируй кэш сторонних/встроенных плагинов и не включай их флагом в конфиге без установки. Если отсутствующий плагин необходим для текущей работы, используй штатную процедуру подключения с учётом поручения и каталога; честно перечисли недоступные возможности. Подключение аккаунтов и дополнительные разрешения выполняются владельцем по мере необходимости. Canva ранее обсуждалась, но установленной не подтверждена и в комплект не входит.

Флаги старых подключений в config.toml не доказывают их работоспособность. Настройки проекта, песочницы, доверенных каталогов, доступов к сети и ускоренного платного режима не переносятся как личные предпочтения.
